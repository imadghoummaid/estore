#e-Store Application

This is a practical example on PHP5.6 and MySQL 5.7 Course. The eStore is a web-based application that's purpose is to manage a products store and the daily transactions on it. If you are not familiar with the coding style in this project please visit the course at https://www.youtube.com/playlist?list=PLrwRNJX9gLs3kkSDgCHFlpgL6qLrlHUBG for more information.

The skeleton has been updated to be compatible with PHP version 8.0+, as of May 4, 2026.
This update transforms the legacy PHP 5.6 skeleton into a modern, secure, and extensible base for web applications. 
Highlights:
- **Architecture**: Migration to PSR-4 standards and Composer-based dependency management.
- **Security**: Mandatory prepared statements in the ORM layer, robust session encryption, and modern password hashing.
- **Features**: A new Routing system and a DI-capable Registry for better code organization.
- **Modern PHP**: Full leverage of PHP 8.x syntax and type safety.
